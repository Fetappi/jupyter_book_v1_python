Домашняя работа. ООП и Git#

Задание 0. Система учёта оценок студентов#

Описание: Управление списком студентов, добавление оценок и расчет среднего балла по группам.

Требуемые классы:

  1. Student (сущность студента):

    • Атрибуты: name, group, grades (список оценок, по умолчанию пустой).

    • Методы: add_grade(grade) (добавление одной или нескольких оценок), average_grade() (расчет среднего балла студента).

  2. StudentManager (менеджер группы):

    • Управляет коллекцией студентов.

    • Методы:

      • add_student(name, group, grades=None) — добавляет нового студента.

      • add_grade(name, grade) — добавляет оценку студенту по имени.

      • average_grade_by_group(group) — возвращает средний балл по группе.

      • remove_student(name) — удаляет студента по имени.

Задание 1. Учёт книг в домашней библиотеке#

Описание: Каталогизация личной библиотеки, отслеживание статуса чтения книг.

Требуемые классы:

  1. Book:

    • Атрибуты: title, author, year, read (булево значение, по умолчанию False).

    • Методы: get_info() (получение форматированного описания книги).

  2. LibraryManager:

    • Методы:

      • add_book(title, author, year) — добавляет новую книгу.

      • mark_as_read(title) — меняет статус книги на «прочитана» (read=True).

      • get_unread_books() — возвращает список названий непрочитанных книг.

      • remove_book(title) — удаляет книгу из списка по названию.

Задание 2. Планирование бюджета на месяц#

Описание: Учёт доходов и расходов по категориям с возможностью фильтрации по датам.

Требуемые классы:

  1. Expense:

    • Атрибуты: category, amount, date.

  2. BudgetManager:

    • Методы:

      • add_expense(category, amount, date) — добавляет новый расход.

      • total_by_category(category) — возвращает общую сумму расходов по категории.

      • filter_by_date(start_date, end_date) — возвращает список расходов за указанный период.

      • delete_expense_by_index(index) — удаляет расход по его индексу в списке.

Задание 3. Трекер привычек#

Описание: Контроль регулярности полезных привычек и расчет прогресса их выполнения.

Требуемые классы:

  1. Habit:

    • Атрибуты: name, frequency, completed_days (список дат).

    • Методы: get_progress() (расчет процента выполнения привычки).

  2. HabitManager:

    • Методы:

      • add_habit(name, frequency) — добавляет привычку.

      • complete_habit(name, date) — добавляет дату в completed_days.

      • habit_progress() — возвращает словарь {название: процент выполнения}.

      • delete_habit(name) — удаляет привычку по названию.

      • avg_grade_by_student(student) — рассчитывает средний балл студента.

      • failing_students(subject, threshold) — возвращает студентов с оценками ниже порога.

      • clear_old_grades(days) — удаляет оценки старше указанного количества дней.

Задание 27. Каталог книг в библиотеке#

Описание: Расширенный учет книг в библиотеке с контролем утерянных изданий.

Требуемые классы:

  1. CatalogBook:

    • Атрибуты: title, author, year, available (по умолчанию True).

  2. LibraryCatalogManager:

    • Методы:

      • add_book(title, author, year) — добавляет книгу.

      • borrow_book(title) — меняет статус available на False.

      • books_by_author(author) — возвращает книги автора.

      • remove_lost_books() — удаляет книги со статусом available=False более 365 дней.

Задание 28. Учёт заказов в кафе#

Описание: Автоматизация работы кафе, расчет выручки и статусов заказов.

Требуемые классы:

  1. CafeOrder:

    • Атрибуты: table, items, total, status (по умолчанию 'в работе').

  2. OrderManager:

    • Методы:

      • add_order(table, items, total) — добавляет заказ.

      • complete_order(table) — меняет статус на «выполнен».

      • revenue_today() — считает выручку за день.

      • cancel_order(table) — отменяет и удаляет заказ.

Задание 29. Список задач для волонтёров#

Требуемые классы:

  1. VolunteerTask:

    • Атрибуты: task, volunteer, date, completed (по умолчанию False).

  2. VolunteerTaskManager:

    • Методы:

      • assign_task(task, volunteer, date) — назначает задачу волонтёру.

      • mark_completed(task) — отмечает задачу выполненной.

      • tasks_by_volunteer(volunteer) — возвращает задачи волонтёра.

      • remove_expired_tasks(date) — удаляет задачи с датой раньше указанной.

Задание 30. Каталог фильмов для стриминга#

Описание: Стриминговая платформа с отслеживанием счетчиков просмотров фильмов.

Требуемые классы:

  1. StreamingMovie:

    • Атрибуты: title, genre, duration, watched (по умолчанию 0).

  2. StreamingCatalogManager:

    • Методы:

      • add_movie_to_catalog(title, genre, duration) — добавляет фильм.

      • increment_watches(title) — увеличивает счётчик просмотров на 1.

      • most_watched_movies(n) — возвращает топ‑n фильмов по просмотрам.

      • remove_movie(title) — удаляет фильм из каталога.

Задание 31. Учёт инвентаря спортивного зала#

    • Атрибуты: item, quantity, condition, location.

  2. GymInventoryManager:

      • update_quantity(item, new_quantity) — обновляет количество.

      • low_stock_items(threshold) — возвращает инвентарь ниже порога количества.

      • dispose_item(item) — удаляет предмет.
