# Домашняя работа

**Общие требования ко всем заданиям:**
* Программа должна быть реализована с использованием **объектно-ориентированного подхода (ООП)**.
* В каждом задании необходимо спроектировать **два класса**:
  1. **Класс-сущность** — описывает отдельный объект предметной области (студент, книга, расход и т. п.).
  2. **Класс-менеджер** — инкапсулирует коллекцию объектов и логику управления ими (добавление, удаление, фильтрация, анализ данных).
* Оформление кода должно строго следовать стандарту **PEP 8**.
* Работа выполняется в репозитории Git, изменения фиксируются осмысленными коммитами.
