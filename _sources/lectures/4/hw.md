## Задание 0. Система учёта оценок студентов

**Описание:** Управление списком студентов, добавление оценок и расчет среднего балла по группам.

**Требуемые классы:**

1. **`Student`** (сущность студента):
   * Атрибуты: `name`, `group`, `grades` (список оценок, по умолчанию пустой).
   * Методы: `add_grade(grade)` (добавление одной или нескольких оценок), `average_grade()` (расчет среднего балла студента).

2. **`StudentManager`** (менеджер группы):
   * Управляет коллекцией студентов.
   * Методы:
     * `add_student(name, group, grades=None)` — добавляет нового студента.
     * `add_grade(name, grade)` — добавляет оценку студенту по имени.
     * `average_grade_by_group(group)` — возвращает средний балл по группе.
     * `remove_student(name)` — удаляет студента по имени.
