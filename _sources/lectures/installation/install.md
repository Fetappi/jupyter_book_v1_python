# Установа Python, VS Code, Git

## Python

1. Заходим на официальный сайт [python.org](https://www.python.org/downloads/)
2. Скачиваем **Download Python install manager**
3. Для проверки установки заходим в терминал: **win+R** -> **cmd** -> 
```bash
**python --version** 
```
В терминале должен отобразится версия текущая питона. 

И также проверяем: **win+R** -> **cmd** -> 
```bash
**pip --version** 
```

## VS Code
1. Заходим на официальный сайт [VS Code](https://code.visualstudio.com/Download/)
2. Скачиваем установочный файл и устанавливаем его.

## Git
1. Заходим на официальный сайт [GIT](https://git-scm.com/install/windows)
2. Скачиваем установочный файл и устанавливаем его.

## Расширения VS Code
1. Открываем VS Code и слева находим вкладку Extensions.
2. Пишем в поисковике **Python** и устанавливаем его.
3. Полезные расширения: **Ruff**, **Jupyter**, **Code Spell Checker**, **Russian - Code Spell Checker**

## Создание проекта
1. Открываем папку проекта. Надо будет нажать доверять тому проекту. 
2. Вызываем поиск команд VS Code. Для того нажимаем наверху по центру поисковую строку, и выбираем второй пункт **Show and Run Commands**, либо же через быстрый доступ: **Ctrl+Shift+P**. 
3. Ищем **Python: Select Interpreter** в поисковой строке. Выбираем первую строку: **Create Virtual Environment**. Дальше в основном выбираем первую строку.
4. Вызов внутреннего терминала: у вас должна появится папка **venv** или **.venv**. При вызове внутреннего терминала: наверху находим вкладку **Terminal** -> **New Terminal**, или же через быстрый доступ: **Ctrl + \`** (*Знак \` на русской раскладке буква ё*).
5. Проверка: После вызова терминала, у вас должна первые строки заскриптованы, они вызывают виртуальное окружение. Спустя пару секунд терминал будет ожидать ввода, а слева будет зеленым выделено ваше виртуальное окружение.
